# ncmd —— 命令行网易云音乐 搜索 / 试听 / 下载

在批处理（命令行）里完成：**扫码登录 → 输入歌名搜索 → 列表选号 → 自动播放 → 确认下载**。
确认后自动拿到歌曲 ID，走 `wyapi.toubiec.cn` 同源解析接口，把**音乐文件 + 歌词文件**一起存到
`D:\music`（可在 `config.json` 里改）。

---

### 运行前提

| 依赖 | 是否必需 | 说明 |
| --- | --- | --- |
| Python 3.9+ | 必需 | 只用标准库；`启动.bat` 会自动找 Python |
| ffplay（ffmpeg 自带） | 试听需要 | 已检测到 `C:\Program Files\ffmpeg\bin\ffplay.exe` |
| ffmpeg | 可选 | 用于把「标题/歌手/专辑」写进音频文件标签；缺失时自动跳过 |

> 本机 `python` 命令指向 Microsoft Store 的占位程序，所以 `启动.bat` 里已经内置了
> 备用解释器路径（`%USERPROFILE%\.dsh\...\python\python.exe`）。若以后自己装了 Python，
> 脚本会自动优先使用系统 `python`。

## 二、登录方式（启动时会让你选）

程序启动后先让你选择登录方式：

```
==========================================================================
 请选择登录方式
==========================================================================
  1. 手机号登录（短信验证码 / 密码）
  2. 二维码扫码登录（用网易云音乐 App 扫）
==========================================================================
输入 1 或 2 >
```

### 方式 1：手机号登录

```
[1/4] 手机号登录
      国家/地区码（中国大陆直接回车，默认 86）>
      手机号 > 138xxxxxxxx
      登录方式：1 = 短信验证码（推荐）  2 = 手机号 + 密码
      请选择（默认 1）> 1
      √ 验证码已发送
      请输入收到的短信验证码 > 123456
      正在登录 ...
      √ 登录成功：你的昵称（Cookie 已保存到 cookie.txt）
```

- 选 `1` 走**短信验证码**；选 `2` 走**手机号 + 密码**（密码输入时不回显）。
- 验证码发送过频会提示 `操作频繁，请稍候再试`，等一会儿再试即可。
- 国内号码直接回车用默认区号 `86`。

### 方式 2：二维码登录

终端直接打印二维码，用「网易云音乐」App 扫码并确认即可。

### 关于 8821 风控（你遇到的那个报错）

```
[!] 网易风控拦截（8821）：请切换其他登录方式或升级新版本再试
```

这不是程序的问题，而是网易风控对当前扫码环境（网络出口 / 客户端版本）的拦截。
程序现在会**主动识别 8821，并直接询问是否改用手机号登录**：

```
[!] 网易风控拦截（8821）：请切换其他登录方式或升级新版本再试
      是否现在改用手机号登录？（y/n，默认 y）> y
```

按回车即可无缝切到手机号登录。想每次直接走手机号登录，把 `config.json` 里的
`login_method` 改成 `"phone"`；二维码用 `"qr"`；默认 `"ask"`（每次询问）。
命令行也能指定：`--login phone` / `--login qr`。

### 已登录过就直接回车

`cookie.txt` 会保存登录态，下次启动检测到有效 Cookie 会直接复用，不再询问：

```
[1/4] 已使用本地 Cookie 登录：你的昵称
```

若本地 Cookie 已失效，会让你重新选一次登录方式。想强制换账号加 `--relogin`。

## 三、交互流程（搜索 → 试听 → 下载）

```
[2/4] 搜索
      搜索歌曲 > 起风了
      → 逐行列出：序号 / 歌曲 / 歌手 / 时长 / 专辑
        （* 表示 VIP 付费曲，可能取不到直链）

选择序号 > 1
      → 自动取直链并用 ffplay 播放
        【按 q 或 Esc 停止播放，空格 暂停/继续】

是否确认下载这首歌曲？（y = 下载 / n = 取消）> y

[3/4] 解析  → 拿到歌曲 ID，按音质顺序请求解析接口
[4/4] 下载  → 音乐文件（.flac/.mp3/.m4a，按文件头自动识别扩展名）
              + 歌词文件（.lrc，可选同时生成 .srt）

==========================================================================
 下载完成
==========================================================================
  歌曲：起风了 - 冯沁苑(买辣椒也用券)
  音质：无损音质
  目录：D:\music
  音乐：起风了 - 冯沁苑(买辣椒也用券).flac（38.3 MB）
  歌词：起风了 - 冯沁苑(买辣椒也用券).lrc
==========================================================================
```

### 可用命令（在选择序号处输入）

| 输入 | 作用 |
| --- | --- |
| `数字` | 选择该序号歌曲 → 试听 → 确认下载 |
| `:n` | 搜索结果的下一页 |
| `:l` | 重看当前列表 |
| `:s` | 重新输入歌名搜索 |
| `:id 421486605` | 直接按歌曲 ID 下载（可用 `https://music.163.com/#/song?id=421486605` 里的数字） |
| `:h` | 显示帮助 |
| `:q` | 退出 |

命令不区分大小写、也兼容中文全角符号（`:s`、`：s`、`：ｓ`、`s` 都能用）。
直接输入一个歌名也会问你要不要就用它搜索。

每次下载完成后，程序都会再打印一次这行提示，方便继续操作：

```
[i] 可用操作：直接输入序号选择歌曲 | :n 下一页 | :l 重看当前列表 | :s 重新搜索 | :id 歌曲ID 直接下载 | :h 帮助 | :q 退出
```

### 播放中的快捷键

| 按键 | 作用 |
| --- | --- |
| `q` / `Q` / `Esc` | **立即停止播放**，回到程序继续操作 |
| `空格` | 暂停 / 继续 |
| `Ctrl+C` | 停止播放 |

> 实现方式：ffplay 的 stdin 接空管道（不让它抢终端按键），按键全部由本程序读取；
> 暂停用「记住播放位置 → 结束 ffplay → 按位置重启」实现，所以暂停后能接着放，
> 不依赖 ffplay 的交互模式，也不受 `-nodisp` 影响。

## 三、命令行参数（可跳过交互）

```bat
启动.bat --search 晴天                 只搜索并列出结果
启动.bat --download 起风了 --pick 1    按歌名搜索并下载第 1 个结果
启动.bat --id 421486605                直接按歌曲 ID 下载
启动.bat --quality 标准音质 --id 421486605
启动.bat --dir E:\我的音乐 --id 421486605
启动.bat --login phone --relogin       用手机号登录（不询问）
启动.bat --login qr --relogin          用二维码登录（不询问）
启动.bat --selftest                    自检：目录/播放器/接口/二维码
启动.bat --relogin                     忽略本地 Cookie，重新登录
启动.bat --no-play                     选中后不试听，直接问是否下载
```

### 下载到哪里？

**默认 `D:\music`**（不存在会自动创建）。优先级：

1. 命令行 `--dir 目录`
2. `config.json` 里的 `download_dir`
3. 默认值 `D:\music`

若该目录不可写，程序会提示并自动改用 `ncmd-music\downloads\`。

## 五、实现说明

程序没有去点网页上的按钮，而是调用了 `wyapi.toubiec.cn` 页面背后**同一套接口**，
效果一致但稳定得多（页面元素 class 一改就会失效）：

| 用途 | 接口 | 请求体 |
| --- | --- | --- |
| 客户端 IP | `POST /api/ip` | `{timestamp}` |
| 取音频直链 | `POST /api/getSongUrl` | `{id, level, timestamp, ip}` |
| 取歌词 | `POST /api/getSongLyric` | `{id, timestamp, ip}` |
| 歌曲信息 | `POST /api/getSongInfo` | `{id, timestamp, ip}` |

要点：

- **必须带 `ip` 字段**（来自 `/api/ip`），否则接口返回 `400 当前非法提交参数`。
- 接口有**按 IP 的限流**：触发时返回 `429` 并给出等待秒数，程序会读秒等待后自动重试。
- 页面上的九档音质对应 `level` 的九个字符串（见上表），是**字符串不是数字**。
- 歌词接口返回的可能是「逐行 JSON」`{"t":17830,"c":[{"tx":"..."}]}`，也可能是标准 LRC 文本，
  程序两种都能解析，并自动过滤作词/作曲/编曲等元数据行。
- 登录部分（两种方式）：

  | 方式 | 接口 | 说明 |
  | --- | --- | --- |
  | 二维码 | `POST /api/login/qrcode/unikey` → 打印二维码 → 轮询 `POST /api/login/qrcode/client/login` | 返回码 `801` 待扫码 / `802` 待确认 / `803` 成功 / `800` 过期 / `8821` 风控 |
  | 短信验证码 | `POST /api/sms/captcha/sent` + `POST /api/w/login/cellphone`（`captcha`） | 区号参数同时兼容 `countrycode` 与 `ctcode_86` |
  | 手机号密码 | `POST /api/w/login/cellphone`（`password`） | 密码输入用 `getpass`，不回显 |

  - 登录请求会带上 `deviceId / os / appver / osver / channel` 这些 cookie（真实网页端本来就会带），
    `deviceId` 首次运行生成并持久化在 `device_id.txt`，可降低被风控判为"非法提交参数(ENC)"的概率。
  - 错误码语义：`503` 验证码错误、`501/502` 账号或密码错误、`405` 发送过频、`406` 操作频繁、`8821` 风控。
- 二维码是自研实现（`pyqr.py`）：按 ISO/IEC 18004 标准实现字节模式、GF(256) 里德-所罗门纠错、
  8 种掩码打分、格式信息 BCH(15,5)，仅依赖标准库，不联网、无需 pip 安装。

## 七、常见问题

**Q：播放时按 `q` 停不下来 / 空格不能暂停？**
现在播放期间按 `q` / `Esc` 会立刻停止，空格暂停/继续。如果仍然没反应，多半是你不在真实的
命令行窗口里（例如在 IDE 的输出面板、或输出被重定向的环境里跑，那里没有真正的控制台输入），
请用 `启动.bat` 打开的命令行窗口运行。

排查办法：把 `config.json` 里的 `playback_debug` 设为 `true`，播放时的按键会记录到
`playback_debug.log`，可以看到程序到底收到了哪些键。

**Q：不想试听，选完直接下载？**
加 `--no-play`，或把 `config.json` 里的 `open_player_on_select` 设为 `false`。

**Q：二维码扫描后提示 `8821 请切换其他登录方式或升级新版本再试`？**
这是网易风控拦截，不是程序问题。程序会提示你改用手机号登录（按回车即可切换），
手机号通道不受该限制。也可直接用 `--login phone` 强制走手机号登录。

**Q：短信验证码一直发不出来，提示「操作频繁」？**
网易对同一号码的发送频率有限制（`405` 间隔过短 / `406` 操作频繁），等 1~2 分钟再试，
或改用「手机号 + 密码」方式登录。

**Q：解析失败，提示「没有拿到音频直链」？**
多为 VIP / 数字专辑 / 独家版权曲目，解析站的公共账号没有权限；也可能该曲目已下架。
换个版本（翻唱、Live、纯音乐版）通常可以成功。程序已列出每个音质的失败原因。

**Q：提示 `429 请求过于频繁`？**
解析站按 IP 限流，程序会自动读秒重试；若频繁出现，把 `request_gap_ms` 调大（如 `3000`）。

**Q：搜索结果里没有我要的原唱？**
网易云搜索会返回大量翻唱/Remix。建议在歌名后加歌手名（如 `晴天 周杰伦`），
或直接用 `:id 歌曲ID` 精确下载。

**Q：终端里二维码显示不全？**
把窗口拉宽到 **50 列以上**（推荐 80 列），二维码才能完整扫描。

**Q：不想每次登录？**
`cookie.txt` 会保存登录态，直接回车即可复用；要重新登录用 `--relogin`。
如果完全不需要登录态，把 `config.json` 里的 `login_on_start` 设为 `false`。
